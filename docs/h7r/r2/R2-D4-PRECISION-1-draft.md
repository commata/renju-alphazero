# R2-D4-PRECISION-1: D4 정밀도와 비용 검토 (기존 기록만 사용)

- 상태: 요약 단계 완료(`R2-D4-PRECISION-1/summary.json`), journal 단계는 데스크톱 실행 대기
- 도구: `scripts/h7r_d4_precision.py` (읽기 전용), 테스트 `tests/test_h7r_d4_precision.py`
- 하지 않는 것: 새 학습, Rapfi 실행, 기존 판독 변경, 탐색 예산 변경

## 1. 질문과 전제

- **질문**: 두 D4(baseline, D1)가 얼마나 정밀했는지, 검출할 가치가 있는 효과를 잡으려면 비용이 얼마인지, 그리고 다음 연구 방향을 무엇으로 할지
- **검토 의견에서 받아들인 전제**
  1. 불일치율이 낮다는 것만으로 검출력이 부족하다고 결론 내리지 않는다.
     - 정밀도는 불일치 관측 수, 결과가 갈린 관측 수, 게임 내 상관에 달려 있다.
     - 이번 D4는 구간이 넓으면서 점추정도 0 근처다. 검출력을 높이면 개선이 나올 것이라는 근거는 없다.
  2. "위치당 0.001"(D1 초안 §17.2, 정정)은 기술적 환산값이다. 전체 국면의 신뢰상한이나 승률·기력 상한이 아니다.
  3. 탐색 예산을 늘리면 고르는 수 자체가 바뀌어 평가 대상이 달라진다. 그래서 이 검토의 "확대"는 같은 예산에서 게임 수를 늘리는 것만 뜻한다.
- **정밀도 자료**
  - D4 구간은 원본 게임 단위 bootstrap(396게임, 관측이 없는 게임 포함, 20,000회)이다. 같은 게임의 관측이 함께 움직이므로 게임 내 상관이 구간에 이미 들어 있다.
  - 요약 단계는 이 구간을 표준오차로 바꿔 쓴다.
  - journal 단계는 같은 자료에서 cluster 표준오차와 jackknife 표준오차를 따로 계산하고, 셋 중 가장 큰 값을 쓴다.

## 2. 사전 고정값 (journal 분석 전, D4 점추정과 무관하게)

| 항목 | 값 | 근거 |
|---|---|---|
| 주 효과 크기 δ* | 불일치 관측당 continuation 점수 차 **0.03** | Arena 규모 계산의 최소 향상량 3%p(docs/h7-rl-plan.md, R1 pilot `size`)를, 게임당 불일치 관측 약 1회(0.96–1.38)로 나눈 근사 |
| 민감도 | 0.02, 0.05 | |
| 검출력 | 0.80 | Arena 규모 계산과 같음 |
| 유의수준 | 단측 0.025 | `label95`(95% 구간이 0 위)와 같음 |
| 세 쌍 결합 | 세 쌍 모두 BETTER(`ALL_THREE_BETTER`) | 독립 가정 한계(쌍마다 0.8^(1/3))와 완전 종속 한계(쌍마다 0.8)를 함께 보고한다. 판단에는 독립 한계를 쓴다. |
| 예산 | 데스크톱 24시간 | 위임 상한과 같은 규모 |

- δ*의 환산은 불일치마다 효과가 더해진다고 보는 근사다. Arena 대국의 불일치 수와 효과가 self-play actor 게임과 같다는 보장은 없다. 상한이나 하한이 아니다.
- **제안 규칙** (도구의 `proposal`)
  - δ*를 세 쌍 모두 검출하는 데 드는 시간(독립 한계, 비용 하한)이 24시간 이하면 평가 확대를 제안한다.
  - 넘으면 제안하지 않고, 같은 표본(396게임)의 다음 D4가 검출할 수 있는 최소 효과(MDE)를 함께 보고한다.
  - D2·D5와 Track A 사이의 선택은 사용자가 한다. 도구는 비용과 MDE만 낸다.
- journal 단계는 세 표준오차 중 큰 값을 쓰므로 필요 시간을 늘릴 수만 있다. 그래서 요약 단계의 "제안하지 않음"은 journal 결과로 뒤집히지 않는다.

## 3. 요약 단계 결과 (`summary.json`, 커밋된 summary와 실행 로그만 사용)

| 연구 | 비교 | 관측 | 결정 관측(게임) | 관측 있는 게임 | 표준오차 |

- 결정 관측(승·무·패가 갈린 관측)은 관측의 21–27%다. 관측이 있는 게임은 396게임 중 153–169게임이다.

**필요 게임 수와 시간** (세 쌍 모두, 가장 큰 표준오차 기준. 시간은 하한)

| 연구 | δ | 완전 종속 한계 | 독립 한계 | 시간(종속–독립) |
|---|---:|---:|---:|---:|
| D1 | 0.02 | 5,330 | 7,959 | 74–111 h |
| D1 | **0.03** | 2,369 | 3,537 | **33–49 h** |
| D1 | 0.05 | 853 | 1,274 | 12–18 h |
| baseline | 0.03 | 1,738 | 2,595 | 15–22 h |

- **비용 모형** (396게임당, 측정값)
  - D1: D4 재생 281.0분(모델 7개) + Rapfi 10.0분 + self-play 39.3분 = 5.5시간
  - baseline: 재생 158.1분(모델 5개) + Rapfi 2.8분 + self-play 39.3분 = 3.3시간
  - 들어가지 않은 것: 새 게임의 label·cache 생성 시간(측정 기록 없음), 봉인과 기록 작업. 그래서 비용은 하한이다.
- **새 게임의 출처**
  - 새 봉인 self-play로 만들어야 한다.
  - H-conf는 확인 판정용으로 예약돼 있고 계약마다 한 번만 열 수 있으므로 쓰지 않는다.
- **396게임에서의 MDE** (세 쌍 모두, 독립 한계): D1 0.090, baseline 0.077
  - 같은 표본의 다음 D4는 이 정도 효과만 80%로 확정할 수 있다.
  - 이것은 δ*의 약 3배다.
- **도구의 제안 규칙 결과**
  - D1: **평가 확대 제안 안 함.** δ*에 49.1시간 이상 필요하다.
  - baseline: 규칙상 제안. 21.9시간으로 예산 안이다. 다만 label·cache 시간이 빠진 하한이라 실제로는 예산을 넘을 수 있다. 또 baseline 후보(c8 recipe seed 대 c5)는 지금 검토하는 후보가 아니다.

## 4. journal 단계 (데스크톱, 읽기 전용, 수 분)

- **하는 일**
  - D1 D4의 `replay.jsonl`과 `branches.jsonl`에서 관측과 branch 결과를 D4 도구와 같은 방식으로 다시 만든다.
  - branch마다 수순을 다시 두어 결과를 확인한다.
  - 커밋된 통계가 그대로 나오는지 대조한다. 다르면 멈춘다.
- **추가로 내는 것** (비교마다)
  - 게임별 관측·결정 관측 분포: 최댓값, 상위 10% 게임의 몫
  - cluster 표준오차, jackknife 표준오차, 독립 관측 가정 대비 design effect
  - 게임 하나를 뺐을 때 점추정이 가장 크게 움직이는 폭
- **바뀔 수 있는 것**: 집중도 해석, 그리고 필요 시간(늘어나는 쪽으로만)

```bash
(
  set -euo pipefail
  cd ~/renju-h6
  source .venv/bin/activate
  export PYTHONPATH="$PWD/src:$PWD/scripts"
  git pull --ff-only origin feat/h7-c1
  test -z "$(git status --porcelain --untracked-files=no)"
  X=docs/h7r/r2/R2-D4-PRECISION-1
  test ! -e "$X/journals.json"
  python -u scripts/h7r_d4_precision.py journals --run-dir runs/h7r/R2-D1-D4-1/full \
    --cache runs/h7r/R1-HDEV-1/cache --output "$X/journals.json"
  git add "$X/journals.json"
  git commit -m "H7-R D4 precision: D1 journal analysis (records only)"
  git push origin feat/h7-c1
)
```

## 5. 잠정 제안 (요약 단계 기준, journal 결과로 보완)

- **평가 확대: 제안하지 않는다.**
  - D1 후보에서 δ*를 확정하려면 새 봉인 게임 2,400–3,500개와 33–49시간 이상이 필요하다.
  - 효과가 없다는 결과도 정보이지만, 이 비용에 견줄 만한 정보는 아니다.
- **D2·D5**
  - 학습, H-dev, D4로 이어지는 한 주기가 하루 안팎 걸린다.
  - 끝에 오는 D4를 지금 표본으로 하면 0.08–0.09 이상의 효과만 확정할 수 있다.
  - 이 크기(δ*의 약 3배)의 선택 효과를 기대할 근거는 지금 기록에 없다.
  - 진행한다면 D4 표본 확대 비용(후보마다 하루 이상)을 함께 계획해야 한다.
- **Track A 전환**
  - 이것을 제안한다.
  - 근거는 Track B value 경로의 비용 구조다. 추가 정보 하나를 얻는 데 하루 이상이 든다.
  - Track A가 더 좋은 결과를 낼 것이라는 증거는 아니다.
  - 전환 범위와 첫 단계, 그리고 그 단계의 판정 기준은 별도 계획으로 정해야 한다.
- 최종 선택은 사용자가 한다.
