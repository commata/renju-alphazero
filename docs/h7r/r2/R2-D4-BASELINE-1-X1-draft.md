# R2-D4-BASELINE-1 X1 — D4 기록의 사후 탐색 부록 초안

작성일: 2026-11-02. 상태: **draft / 미승인 / 실행 불가**.

- 기존 D4 기록만 읽는 **사후(post-hoc) 탐색**이다.
- 하지 않는 것: 새 탐색, Rapfi 대국, 학습
- D4 판독(`NOT_ESTABLISHED`), c5 유지, V9 보류는 바꾸지 않는다.
- 결과는 다음 하위 계약을 고르는 참고 자료이며, 독립 증거나 확인 근거가 아니다.
- 실행하려면 도구 구현, 이 문서의 확정, 실행 승인이 각각 필요하다.

## 1. 질문

D4 full에서 세 seed 모델은 c5와 eligible 국면의 약 3%에서 다른 수를 골랐다. 그 수의 continuation 점수가 낫다는 신호는 없었다. 이 부록은 그 불일치가 어떻게 생기는지를 기술적으로만 살펴본다.

1. 불일치와 결과가 어느 ply와 차례에 몰리는가
2. 결정 관측(우세 또는 열세)이 소수 대국이나 특정 국면에 집중되는가
3. 세 seed의 관측과 결과가 얼마나 겹치는가(공유 분기 고려)
4. 예측 값과 탐색 값의 변화가 continuation 결과와 어떤 관계를 보이는가

**시작 조건**
- 도구는 시작 전에 위 SHA를 대조한다.
- D4 full 검증기와 같은 방식으로 관측과 분기를 다시 구성해, summary의 건수와 같은지 확인한다.
- 다르면 멈춘다.

## 3. 분석 항목 (사전 지정, 기술 통계만)

공통
- 관측 단위는 D4의 불일치 관측이다. 판독용 삼분류는 VALID와 구조적 무승부를 쓰고, 미해결은 이번 결과에 없다.
- 세 seed 비교와 c8 참고를 따로 집계한다.

**3.1 ply와 차례**
- ply 구간: [5, 20), [20, 40), [40, 80), [80, ∞). R2와 같다.
- 차례: 흑 / 백
- 구간마다 보고하는 것: eligible 국면 수, 불일치 수와 비율, 우세 / 열세 / 동일, 결정 관측 수, 구간별 mean_delta
- 구간별 구간 추정은 하지 않는다. 다중 비교의 우연을 해석하지 않기 위해서다.

**3.2 집중도**
- 비교마다 결정 관측이 있는 게임 수
- 상위 10판이 차지하는 결정 관측과 우세 − 열세의 몫, 한 판의 최댓값
- 같은 국면 history가 여러 대국에 반복된 관측의 수(opening 반복)

**3.3 seed 간 겹침**
- seed 쌍마다 같은 (게임, ply)에서 둘 다 불일치한 관측 수
- 그중 후보 수까지 같아 분기를 공유한 수
- 공유 관측에서 결과(우세 / 열세 / 동일)가 일치하는 비율
- 세 seed 합집합의 불일치 국면 수
- 공유 분기는 같은 Rapfi 대국 결과를 쓰므로, 겹침이 크면 seed 결과의 일치는 독립 반복이 아니다.

**3.4 예측·탐색 값 변화와 결과**

**값 비교의 구분**: 두 모델이 각자 고른 수의 Q를 서로 빼는 것은 선택 우열의 직접 척도가 아니다. 모델마다 값 보정이 다르기 때문이다. 그래서 아래처럼 나눈다.

| 구분 | 정의 | 용도 |
|---|---|---|
| **모델 안 비교(주)** | 같은 모델의 root visits 목록에 두 후보 수(후보 모델의 수, c5의 수)가 모두 있을 때, 그 모델의 Q 차이 Δq_in = Q(후보 수) − Q(c5 수). 후보 모델과 c5 각각에 대해 따로 계산한다 | 결과와의 관계 |
| **방문 몫 차이** | 같은 모델 안에서 두 수의 방문 비율 차이 | 보조 |
| **값 없음** | 한쪽 수가 그 모델의 root 목록에 없는 경우 | 건수만 세고, 위 계산에 넣지 않는다 |
| **모델 간 Q 차이** | 각 모델이 고른 수의 Q 차이 | 보정이 섞인 값임을 명시하고 분포만 보고한다. 결과와의 관계 판단에는 쓰지 않는다 |
| **국면 예측 차이** | 그 국면의 H-dev 예측 \|v_후보 − v_c5\|(D4 평균, `seed_predictions.pt`) | 불일치가 생긴 국면과 그렇지 않은 국면의 분포 비교, 결과별 분포 |

**관계 요약**
- Δq_in과 국면 예측 차이를 사전 지정한 사분위로 나눈다. 경계는 결과를 보기 전에 정하며, 해당 국면 집합의 값 분포에서 계산한다.
- 칸마다 우세 / 열세 / 동일과 mean_delta를 보고한다.
- 상관계수나 검정 p값은 내지 않는다.

## 4. 보고와 금지

- 결과는 집계 수치만 담는다: `records/x1/x1_summary.json`과 도구 출처 SHA. 행별 자료와 raw journal은 `runs/`에 남는다.
- 결과를 보고 다음을 하지 않는다.
  - D4 판독, 계약, 표본, 예산 변경
  - 새 판독 label 만들기
  - 특정 구간만 골라 개선을 주장하기
- 이 부록에서 유망해 보이는 구간이 나와도, 그것을 확인하려면 새 표본의 별도 계약이 필요하다.

## 5. 확정 전 선택

1. 위 네 분석 항목과 정의(특히 3.4의 모델 안 비교와 값 없음 처리)
2. ply 구간과 사분위 경계 규칙
3. 입력에 R2-0B의 `seed_predictions.pt`를 포함할지(3.4 국면 예측 차이)
4. 승인 단계 분리: 도구 구현·테스트 → 데스크톱 실행
