# 규칙 결정 기록 (v0.2)

참고: [Renju International Federation 국제 규칙](https://www.renju.net/rifrules/), [규칙 소개](https://www.renju.net/rules/). 대회용 개국 및 색 교환 절차는 이 버전에서 사용하지 않습니다. 자유 착수로 흑이 먼저 둡니다.

| 항목 | 판정 |
| --- | --- |
| 흑 승리 | 방금 둔 돌을 포함해 한 방향으로 정확히 5개 연결 |
| 백 승리 | 방금 둔 돌을 포함해 한 방향으로 5개 이상 연결 |
| 흑 장목 | 어느 방향으로든 6개 이상 연결하면 금수. 동시에 5목이어도 금수 |
| 흑 사사 | 착수로 생긴 서로 다른 두 개 이상의 4가 있으면 금수. 하나의 곧은 4에서 양 끝의 5목 완성점은 같은 4로 셈 |
| 흑 삼삼 | 착수로 서로 다른 두 방향에 열린 3을 만들면 금수. 열린 3은 한 수를 더 두어 양 끝에서 정확히 5목을 완성할 수 있는 곧은 4로 발전할 수 있어야 하며, 그 연장 수 자체가 금수라면 유효한 3으로 세지 않음 |
| 우선순위 | 장목 → 정확히 5목 승리 → 사사 → 삼삼 → 일반 착수 |
| 무승부 | 다음 차례에 합법수가 없을 때 |

## 재귀적 삼삼 판정

RIF 국제 규칙 9.3은 겉으로 삼삼처럼 보이는 형태라도 각 3을 곧은 4로 발전시키는 연장 수가 실제로 허용되는지를 계속 확인하도록 요구합니다. 연장 수가 장목·사사 또는 다시 금지된 삼삼을 만들면 그 방향은 유효한 열린 3으로 세지 않습니다.

현재 구현은 다음 방식으로 이를 판정합니다.

1. 흑의 후보 착수를 보드에 임시로 둡니다.
2. 각 방향에서 실제 곧은 4를 만드는 연장 후보만 찾습니다.
3. 해당 연장 수를 둔 상태에서 같은 금수 판정기를 다시 호출합니다.
4. 연장 수가 금수이면 그 방향의 3은 유효하지 않은 것으로 처리합니다.
5. 재귀 호출 동안 상위 단계에서 둔 임시 돌은 보드에 남아 있으므로 다음 단계는 항상 새로운 빈칸을 추가해 진행합니다.
6. 모든 임시 착수는 판정 후 원상 복구합니다.

회귀 테스트에는 겉보기에는 삼삼이지만 한 방향의 유일한 연장 수가 다시 금지된 삼삼이 되는 사례를 포함합니다. 이 경우 원래 착수는 유효한 3이 하나뿐이므로 삼삼 금수로 처리하지 않습니다.

이 버전은 자유 착수 엔진을 위한 규칙 구현입니다. 공식 대회의 개국·색 교환 절차와 시간 규정은 포함하지 않으며, 국제 규칙의 모든 예시를 형식 검증한 판정기라고 단정하지 않습니다. 추가 규칙 사례는 회귀 테스트로 계속 확장합니다.
